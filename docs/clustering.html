3 Recipe

Our recipe4:

  1. Specifies the key i.e. LSOA21CD.
  2. Removes selected variables e.g. cycle_infra_length_m.

Some notes on selecting and transforming candidate variables are in the EDA page

Code 
# LSOA21CD is kept as an ID so it is not used as a clustering predictor
lsoa_rec <- recipes::recipe(~ ., data = df_lsoa) |>
  recipes::update_role(LSOA21CD, new_role = "id") |>

    count_point_n,

8 Evaluate

The fitted workflow keeps the trained model and the prepped recipe, but not the training rows. kmeans_fit holds the k-means centres and cluster assignments, so it can label the data it was trained on, but it can’t recompute distances from the original observations. The metrics we’re going to use need those distances, so they need to take the data as an argument.

# Evaluate

The fitted workflow keeps the trained model and the prepped recipe, but not the training rows. `kmeans_fit` holds the k-means centres and cluster assignments, so it can label the data it was trained on, but it can't recompute distances from the original observations. The metrics we're going to use need those distances, so they need to take the data as an argument.

```{r}
#| label: evaluate

tidyclust::sse_within_total(kmeans_fit, df_lsoa)
tidyclust::sse_ratio(kmeans_fit, df_lsoa)
tidyclust::silhouette_avg(kmeans_fit, df_lsoa)
```
